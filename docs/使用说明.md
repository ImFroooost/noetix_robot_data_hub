# Noetix Robot Data Hub 使用说明

按角色各写一份。发给谁就看哪一份。

登录后，右上角用户名下面是角色名。点 **使用说明** 会打开当前角色的手册。登录成功后也会自动弹出一次。

站点里实际显示的是 `frontend/public/help/roles/` 下的文件。本目录是同一套说明的副本。

---

普通角色必须由超级管理者配置范围。超级角色看全库。只有超级管理者能开账号、看操作记录、管理重定向。

所有人都能进 **浏览**、**3D 模型** 和 **可视化**。可视化页会在画面下显示原始数据，并跟着播放进度更新。浏览、上传、标注、数据管理里的预览窗口只显示画面。

---

## 给超级管理者

1. 在 **用户与权限** 创建账号并选角色。
2. 普通角色要 **配置范围**，再用 **进入视角** 看对方的真实列表。
3. 把上表里对应的那一份发给对方，或让对方登录后点 **使用说明**。
