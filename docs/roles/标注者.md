# 标注者使用说明

本文只写给角色为 **标注者** 的账号。登录后右上角应显示：`你的用户名（标注者）`。

你的工作是给已有数据补全、修正分类和人员信息。浏览页里标签多为只读，请到顶部 **标注** 再改。

---

## 你能做什么 / 不能做什么

| 能 | 不能 |
| --- | --- |
| 浏览范围内的数据并预览 | **下载**打包（默认没有） |
| 在 **标注** 页改分类、姓名、性别、身高、评价、备注 | 上传新文件 |
| 改机器人数据的款式 / 版本 | 删除、管用户 |

只能改范围内的数据。需要下载时，请联系管理员开通。

---

## 登录与菜单

登录后你会看到：**浏览** · **标注** · **3D模型管理**。

请养成习惯：先 **浏览** 找数据，再进 **标注** 保存修改。

## 怎么改一条数据单元的标签

1. 打开顶部 **标注**。
2. 用筛选或搜索找到目标单元，左侧点中它。
3. 右侧下拉选择分类（可逐级点到叶子，如「所属项目 → GMT → 动作表0」）。
4. 补全姓名、性别、身高；需要时选数据评价、写备注。
5. 点 **保存标签**。
6. 再点开该单元里的 `bvh` / `fbx`，确认文件上也带上了同样分类。

改**批次**上的分类时：左侧点批次名（不要点进单元），右侧保存后，该批次下单元和文件会跟着更新。

---

## 改单个文件

中间点某个格式（只改这一份 fbx 或某一段视频）时，右侧改的是文件级覆盖。一般项目/采集信息建议改在单元上，一次同步到所有格式。

---

## 常见问题

**浏览页右侧不能改？**  
到 **标注** 菜单再改。

**保存单元后，文件上还是「请选择」？**  
Ctrl+F5 刷新，并确认点的是同一个单元里的文件。

**我想改「某一次上传」的参数？**  
你没有「上传」菜单，看不到上传记录列表。请直接改对应的数据单元或文件。

**没有下载按钮？**  
标注者默认不能下载。
