# 超级标注者使用说明

登录后，右上角用户名下面应显示 **超级标注者**。

你能做的事和 **标注者** 一样：浏览、预览、改分类和人员信息。区别是你改的是 **全库**，不用配置范围。

不能下载、不能上传、不能删除、不能管用户。

---

## 你能看到的菜单

**浏览** · **标注** · **3D 模型** · **可视化**

---

## 怎么改

1. 在 **浏览** 或 **标注** 里找到批次和数据单元。可以用搜索。
2. 打开 **标注**，点中单元。
3. 右侧修改分类、姓名、性别、身高、评价、备注，点 **保存标签**。
4. 改在单元上的分类会同步到该单元的文件。只想改一份文件时，先点开那个格式，再保存。

机器人款式、模型版本要和 **3D 模型** 里的实例一致。改错了用右上角 **撤销**。

**可视化** 只看本机文件，原始数据跟着当前帧更新。**3D 模型** 只读。
