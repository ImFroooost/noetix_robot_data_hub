# 超级标注者使用说明

本文只写给角色为 **超级标注者** 的账号。登录后右上角应显示：`你的用户名（超级标注者）`。

你负责给**全库**已有数据补分类和人员信息。不能上传、默认也不能下载。

---

## 你能做什么 / 不能做什么

| 能 | 不能 |
| --- | --- |
| 浏览、预览全库 | 下载打包 |
| 在 **标注** 页改任意批次/单元/文件的标签 | 上传、删除、管用户 |
| 改人体姓名/性别/身高、机器人款式/版本、评价与备注 | |

**浏览** · **标注** · **3D模型管理**

务必在 **标注** 页保存修改；浏览页一般为只读展示。

## 标准标注流程

1. 打开 **标注**。
2. 按所属项目或搜索定位单元。
3. 左侧点数据单元（或点批次做整批统一）。
4. 右侧选分类、补人员信息或机器人款式。
5. **保存标签**。单元/批次上的分类会同步到其中的文件。
6. 点开 `fbx`/`bvh` 抽查文件右侧是否已带上同样标签。

## 常见问题

**想下载或上传？**  
当前账号做不到，请联系管理员开通相应权限。

**没有「上传顺序」？**  
你没有上传菜单，不能按「某一次导入」改记录，请直接改单元或文件。
