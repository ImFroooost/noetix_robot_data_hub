# 管理者使用说明

本文只写给角色为 **管理者** 的账号。登录后右上角应显示：`你的用户名（管理者）`。

你可以在范围内浏览、下载、标注、上传，还可以**整理（删除）数据**、**维护分类树**。范围由管理员配置，**不能管用户**。

---

## 你能做什么 / 不能做什么

| 能 | 不能 |
| --- | --- |
| 范围内浏览、下载、标注、上传 | 创建/改别人的账号 |
| **数据管理**：删批次、单元、文件；看到空批次 | 给别人配范围、进入别人视角 |
| **分类管理**：增删改分类标准与节点 | 看到范围外的数据 |
| 删除 3D 模型实例或模型文件 | |

「管理数据」在范围内同时覆盖浏览、下载、标注、上传。

---

## 登录与菜单

**浏览** · **上传** · **标注** · **数据管理** · **分类管理** · **3D模型管理**

没有 **用户管理**。要开账号请联系能管理用户的管理员。

## 1. 上传与标注

1. **上传** 页先选预设分类，再拖文件夹/zip。
2. 在 **上传顺序** 里点本次记录，核对右侧参数并保存。
3. 历史数据到 **标注** 页改单元/批次标签，保存后同步到文件。

## 2. 数据管理（删除与整理）

打开 **数据管理**（和浏览同一套三栏，但有删除、且能看到空批次）。

![浏览三栏，管理页同样布局](../images/ui-browse-unit.png)

1. 左侧选中要处理的批次、单元或中间的文件。
2. 红色 **删除** 按钮：删本次上传 / 删当前文件 / 按选择删批次或单元。
3. 确认对话框看清名称再确定。**删除不可恢复。**

先预览确认是不是目标数据，再删。传错文件优先删文件，不要整批误删。

---

## 3. 分类管理

打开 **分类管理**：

1. 左侧选分类标准（所属项目、获取方式、GMT 快速分类等）。
2. 树上点节点：改名、加子节点、调整顺序。
3. 需要时新建一条分类标准。
4. 内置标准被改乱，可用「恢复标准结构」（尽量保留已有节点和已打标签）。

注意：

- 改树**不会**自动改已经打在文件上的旧标签，只影响以后的下拉选项。
- 若删光子节点后刷新又冒出默认树，先留一个子节点再整理。

---

## 4. 3D 模型

可上传，也可删除实例或单个模型文件。机器人「款式」须对应这里的实例名。

## 常见问题

**我删不了某个批次？**  
可能不在你的范围内，或不是管理者角色。

**想给组员开账号？**  
当前账号不能管理用户。把需要的用户名、角色、范围路径发给能管用户的管理员即可。

**上传后列表里暂时没有？**  
本站上传结束应立刻可见。从磁盘直接拷进去的文件，最多约 10 分钟进索引。
