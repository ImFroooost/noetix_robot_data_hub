# 超级下载者使用说明

登录后，右上角用户名下面应显示 **超级下载者**。

你能做的事和 **下载者** 一样：浏览、预览、下载、看 3D 模型和本地可视化。区别是你看的是 **全库**，不用配置范围。

不能改标签、不能上传、不能删除、不能管用户。

---

## 你能看到的菜单

**浏览** · **3D 模型** · **可视化**

---

## 浏览和下载

1. 打开 **浏览**，在左侧找到批次和数据单元，或搜索后点 **搜索**。
2. 点开单元。人体在左，机器人在右。机器人先选款式，再选 omniretarget 等获取方式。
3. 点格式按钮，用 **同屏预览** 确认内容。可以添加窗口、对比、播放。
4. 用 **下载此单元**、当前文件下载，或勾选后点 **下载**，把数据打包带走。

机器人合并 npz、zip 里是动作和物体轨迹，网格在 **3D 模型** 里，要模型时另下对应款式。
