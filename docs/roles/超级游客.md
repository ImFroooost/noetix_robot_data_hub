# 超级游客使用说明

本文只写给角色为 **超级游客** 的账号。登录后右上角应显示：`你的用户名（超级游客）`。

你是**只读**账号，可以看**全库**，不用单独配置范围。

---

## 你能做什么 / 不能做什么

| 能 | 不能 |
| --- | --- |
| 浏览全库数据、筛选、搜索、同屏预览 | 下载打包 |
| 查看任意批次/单元/文件的标签（只读） | 改分类、姓名、评价 |
| 查看全部 3D 模型 | 上传、删除、管用户 |

适合给需要「看全库、但不能改、不能带走」的评测或参观账号。

---

## 登录

1. 浏览器打开站点（例如 `http://服务器IP/`）。
2. 输入用户名和密码，点 **登录**。
3. 默认进入 **浏览**。用完点右上角 **退出**。

---

## 你能看到的菜单

**浏览** · **3D模型管理**

没有上传、标注、数据管理、用户管理。

## 日常操作

1. **按结构逛：** 分类标准选「存储结构」，左侧展开批次 → 数据单元。
2. **按项目逛：** 点「所属项目」，下拉选 GMT / 动作表等，列表会收窄。
3. **搜索：** 输入批次名或单元名，回车。
4. **预览：** 点 `fbx` / `bvh` / 视频格式，文件进入下方窗口；可开多个窗口对比。
5. **对标签：** 点批次、单元或文件，右侧查看所属项目、采集方式、姓名等，不能保存修改。

`.fmdata` 无法在浏览器预览时，请让有下载权限的同事导出。

## 常见问题

**我想下载？**  
当前账号不能下载，请联系管理员开通。

**我想改标签？**  
当前账号不能改标签，请联系管理员开通。

**预览颜色和建模软件不同？**  
只预览运动轨迹，不是最终渲染。
