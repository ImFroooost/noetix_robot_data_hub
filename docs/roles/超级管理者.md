# 超级管理者使用说明

登录后，右上角用户名下面应显示 **超级管理者**。旧数据里的 `admin` 也是这个角色。

你拥有全部菜单和全库权限，并负责开账号、配范围、用「进入视角」验收别人实际能看见什么。也能看重定向进度，并决定新机器人要不要加入自动重定向。

---

## 你能看到的菜单

**浏览** · **上传** · **标注** · **数据管理** · **回收站** · **分类管理** · **重定向管理** · **3D 模型** · **可视化** · **用户与权限** · **操作记录**

右上角还有撤销、重做、**更新索引**、使用说明、改密、退出。

首次部署的默认账号多为 `admin`。密码以现场为准，上线后立刻在 **改密** 里换掉。

---

## 1. 开账号

1. 打开 **用户与权限**。
2. 新建用户：用户名、密码、角色，点创建。
3. 普通角色（游客、下载者、标注者、上传者、管理者）必须 **配置范围**，按批次或分类节点划定他能看见的数据。
4. 超级角色看全库，不用配范围。
5. 对方登录后会看到自己角色的使用说明。之后也可以点右上角 **使用说明**。

| 对方要做什么 | 角色 |
| --- | --- |
| 只看、不改、不下 | 游客，或全库用超级游客 |
| 把数据拷走 | 下载者，或超级下载者 |
| 只补标签 | 标注者，或超级标注者 |
| 往库里传数据和模型 | 上传者，或超级上传者 |
| 还要删除数据、改分类树 | 管理者（记得配范围） |
| 管人、看操作记录、管重定向 | 只留给超级管理者 |

只有超级管理者能进 **用户与权限**。

---

## 2. 进入视角

配完范围后，在用户那一行点 **进入视角**。顶栏会标明你正在看对方的界面，菜单和数据列表就是他登录后的样子。

核对完点 **退出视角**。不要只看配置表。

---

## 3. 停用、改角色、删除账号

在用户表里改角色下拉框。**禁用** 后不能登录，数据还在。**删除** 只去掉账号。至少要留一个可用的超级管理者。

---

## 4. 日常数据

- **浏览**：按批次和数据单元查看。人体、机器人分开。机器人先选款式再选获取方式。同屏预览可播放、添加窗口、对比。
- **上传**：预设分类 → 新建或选择批次 → 文件夹或 zip。机器人必须选已有款式。完成后在上传顺序里保存这次的标签。
- **标注**：改单元或批次的分类和人员信息，保存后同步到文件。
- **数据管理**：删除或重命名批次、单元、文件。删除会先进入 **回收站**。筛选了数据主体、格式或模态后再删除，只会移走筛选到的文件，同单元里其余文件保留。
- **回收站**：恢复误删的文件，或再永久删除。永久删除后不能在网页上找回。
- **分类管理**：维护分类树。改树不会自动改写已经打在旧文件上的标签。
- **可视化**：看本机文件。原始数据只在这一页出现，并跟着当前帧更新。
- **操作记录**：每个用户的每次操作单独一条，用来核对谁改过什么。

人体合并 fbx 与动作同名。机器人合并数据有 fbx、npz、zip，物体是 csv 和 xml。预览里机器人和物体共用坐标系。

右上角 **更新索引** 会完整扫描仓库。平时上传、删除、重命名只更新变动的部分，不必每次都全量重建。

---

## 5. 3D 模型和重定向

### 新机器人模型

1. 打开 **3D 模型** → **机器人模型**。
2. **＋** 新建实例。名字就是款式名。
3. 上传包含网格和 URDF 的 zip。URDF 可以在 `urdf/` 中，也可以和网格放在一起。
4. 选好 **默认描述文件**，点 **检查结构并上传**。

网站会整理成 meshes、urdf、mjcf，并生成重定向配置。这个款式会出现在浏览的款式按钮里，也会出现在重定向优先级的可选机器人里。

已有手调配置的 noetix_e1、noetix_e2、noetix_e2v2_1015、noetix_m5_0、unitree_g1 不会被一次新上传覆盖掉。

只有超级管理者能删除模型实例。

### 重定向管理

打开 **重定向管理**，查看自动重定向的进度。

优先级从上到下执行。每一档同时指定机器人和数据范围。新上传的机器人虽然已经能被重定向程序识别，但要在某一档勾上并 **保存优先级**，当前这一波结束后才会按新顺序跑。

没有被规则点名的 noetix_e2v2_1015、unitree_g1、noetix_e2，仍会排在后面继续做。其他新机器人不会自动开跑。

## 常见问题

**普通用户说看不见数据？**  
进入他的视角看列表，并检查配置范围是批次还是分类节点。

**普通管理者能不能开账号？**  
不能。

**误删数据？**  
打开 **回收站** 恢复。只有在回收站里永久删除之后，才不能在网页上找回。

**新机器人预览是空的，或重定向列表里没有它？**  
确认标准描述已经上传，并且默认描述文件是 URDF。上传成功后刷新浏览页。重定向要另外在优先级里勾选并保存。
