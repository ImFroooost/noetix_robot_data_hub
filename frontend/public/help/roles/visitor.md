# 游客使用说明

本文只写给角色为 **游客** 的账号。登录后右上角应显示：`你的用户名（游客）`。

游客是只读账号：用来核对数据长什么样、标签对不对。你**看不见**上传、标注、数据管理、用户管理。

---

## 你能做什么 / 不能做什么

| 能 | 不能 |
| --- | --- |
| 打开 **浏览**、**3D模型管理** | 下载打包 |
| 筛选、搜索、同屏预览 | 改分类、姓名、评价 |
| 查看右侧标签（只读） | 上传、删除、管用户 |

你只能看到管理员给你「配置范围」里的批次或分类。别人能看见的数据，你这边列表可能更短，这是权限，不是坏了。

---

## 登录

1. 浏览器打开站点（例如 `http://服务器IP/`）。
2. 输入管理员发给你的用户名和密码，点 **登录**。
3. 默认进入 **浏览**。用完点右上角 **退出**。

**浏览** · **3D模型管理**

## 日常操作

### 按批次找一条数据

1. 顶部分类标准保持 **存储结构**。
2. 左侧点开一个数据批次，再点其中一个数据单元（例如 `biantuiquanti-TJC-M-181_040`）。
3. 中间人体数据区会出现 `bvh` / `csv` / `fbx` 等格式标签。

### 按项目筛选

1. 顶部点 **所属项目**（或获取方式、地点等）。
2. 再在下拉里选节点，例如「GMT / 动作表1」。
3. 左侧只留下打了这个标签的数据。

### 搜索

搜索框输入批次名或单元名的一部分，回车或点 **搜索**。

### 同屏预览

1. 点中间的格式标签（如 `fbx`、`bvh`），文件进入下方预览窗口。
2. 可播放、暂停、调速；**添加窗口** 可再开一格对比。
3. `.fmdata` 若提示无法预览，这是正常的，游客也无法下载，请找有下载权限的同事导出。

### 只读看标签

- 点批次 → 右侧看批次分类。
- 点数据单元 → 看所属项目、获取方式、地点、设备等。
- 点具体文件 → 还会看到从上级继承的分类，以及姓名、性别等（不能改）。

## 3D 模型

顶部 **3D模型管理** 可以查看已有人体/机器人模型，只能看，不能上传或删除。

## 常见问题

**别人能看见的批次我没有？**  
请超级管理者检查你的「配置范围」，或让他点「进入视角」按你的账号看一遍。

**预览是绿骨架，和 Maya / Blender 不一样？**  
浏览器里只预览动作，不是最终材质。

**我想下载或改标签？**  
当前账号做不到，请联系管理员开通相应权限。
