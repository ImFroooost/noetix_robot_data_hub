# 超级上传者使用说明

本文只写给角色为 **超级上传者** 的账号。登录后右上角应显示：`你的用户名（超级上传者）`。

你可以对**全库**浏览、下载、标注、上传，但不能删除数据、不能管用户、不能改分类树。

---

## 你能做什么 / 不能做什么

| 能 | 不能 |
| --- | --- |
| 全库浏览、预览、下载 | 删除批次 / 单元 / 文件 |
| 全库标注 | 分类管理、用户管理 |
| 向任意批次上传文件夹、zip、单文件 | 删除 3D 模型实例 |
| 改任意一次上传记录的参数 | |

---

## 登录与菜单

**浏览** · **上传** · **标注** · **3D模型管理**

---

## 上传主流程

![上传步骤](/help/images/guide-upload-flow.png)

![上传页](/help/images/ui-upload.png)

1. 打开 **上传**，先填 **预设分类标签**。
2. **新建批次** 或选已有批次。
3. 拖入文件夹 / zip，或选服务器路径。
4. 确认人体/机器人与模态后导入。
5. 左侧切 **上传顺序**，点开本次记录，右侧核对并 **保存标签**（只改这一次上传的文件）。

![上传记录](/help/images/ui-upload-session.png)

同名文件属于同一数据单元；文件名里的 `skeleton` / `rigid body` / `marker` 及后面内容会去掉后再归组。新后缀按扩展名建格式目录。机器人 CSV 可手填帧率，人体不必。

---

## 其它你常做的事

- **补格式：** 单元矩阵缺省项上的 **+**。
- **改历史标签：** 顶部 **标注**，选批次/单元/文件后保存，会同步到下属文件。
- **下载：** 浏览页中间下载当前文件或打包。
- **3D 模型：** 可新增实例并上传文件，不能删实例。

![浏览预览](/help/images/ui-browse-unit.png)

传错了需要删除时，请联系管理员处理。当前账号不能删除数据。
